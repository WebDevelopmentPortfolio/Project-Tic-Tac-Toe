
### Description

Project Tic-Tac-Toe from <a href="https://www.theodinproject.com/">The Odin Project </a>JavaScript course.

Using HTML, CSS (Flexbox for layout) and JavaScript.

Requirement: 
The main goal of the project is to have as little global code as possible. Try to tuck everything inside factory functions OR IIFEs.

Features:

1. An option for player (You) to (pretend) choose if you want to be player 1 (X) OR player 2 (O).
2. A player to be declared winner after 3 wins in a row.
3. Option to continue the game OR to start over after each win.
4. Ability to start over after winning 3 in a row.

To try the game for yourself, go to https://webdevelopmentportfolio.github.io/Project-Tic-Tac-Toe/.
