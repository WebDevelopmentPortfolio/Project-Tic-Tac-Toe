
### Description

Project Tic-Tac-Toe from <a href="https://www.theodinproject.com/">The Odin Project.</a>

Requirement: 
The main goal of the project is to have as little global code as possible. Try to tuck everything inside factory functions OR IIFEs.

Features:

1. An option for player to (pretend) choose between player 1 (X) OR player 2 (O).
2. A player to be declared as winner after 3 wins in a row.
3. Option to continue the game after each win OR to start over.
4. Ability to start over after winning 3 in a row.
